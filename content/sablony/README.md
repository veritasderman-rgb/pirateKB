# content/sablony/: šablony textů

**Co sem patří:** šablony a struktury výstupů: tisková zpráva, příspěvek na sítě, projev,
brief. Šablona popisuje skutečnou praxi (s odkazem na vzorové texty) a vyplnitelnou
strukturu; pole, která musí doplnit člověk, jsou označena `[DOPLNIT KURÁTOR]`.

**Vztah k `server/prompts/`:** prompty serveru jsou provozní verze pro AI; kurátorovaná
verze tady je zdroj pravdy. Po schválení šablony se má prompt aktualizovat podle ní.

**Kdo schvaluje:** kurátor nebo pověřený správce (u TZ mediální odbor).

**Schéma:** [`schemas/sablona.schema.json`](../../schemas/sablona.schema.json)
(`typ: sablona`, volitelně `pro`).
