# content/organizace/: jak strana funguje

**Co sem patří:** kurátorované texty o fungování strany, které automatická evidence
neobsahuje nebo je v ní nesrozumitelně: kdo za co odpovídá, kam se s čím obrátit,
schvalovací postupy (např. kdo schvaluje TZ, kdo smí mluvit za stranu), přehled systémů
pro nové členy. Kontakty jen oficiální (role, e-mail `@pirati.cz`); interní kontakty
výhradně s `viditelnost: clenske`.

**Co sem nepatří:** kopie evidence lide.pirati.cz (ta je v `data/lide/` a aktualizuje se
sama), seznamy řadových členů, soukromé kontakty.

**Kdo schvaluje:** kurátor nebo pověřený správce.

**Schéma:** [`schemas/organizace.schema.json`](../../schemas/organizace.schema.json).

Zatím prázdné. Kandidát: `data/systemy/kam-s-problemem.md` (návrh ke schválení).
