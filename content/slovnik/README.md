# content/slovnik/: zkratky a pirátské pojmy

**Co sem patří:** výklad zkratek orgánů a jednotek (CF, RV, KS, MS, RT…) a pirátského
slangu a systémů (nalodění, Maják, mrak, Piroplácení…), aby AI i nováček rozuměli
interním textům.

**Jak vzniká:** tabulky organizačních jednotek se generují z evidence
(`data/lide/tymy/`, `data/lide/regiony/`) a ručně se neupravují; ručně psané pojmy jsou
v samostatném oddílu se sloupcem „ověřeno“.

**Kdo schvaluje:** kurátor nebo pověřený správce (např. člověk z administrativního odboru).
Ověření pojmu = odkaz na předpis nebo oficiální stránku.

**Schéma:** [`schemas/slovnik.schema.json`](../../schemas/slovnik.schema.json).
