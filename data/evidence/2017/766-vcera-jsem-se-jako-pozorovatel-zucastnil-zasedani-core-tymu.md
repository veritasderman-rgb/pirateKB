# Včera jsem se jako pozorovatel zúčastnil zasedání core týmu Tak jo!

Schůzka 11. 9. 2017. Zapsal/a: Mikulas Peksa (zveřejněno 2017-09-11 v Evidenci kontaktů a schůzek).

Včera jsem se jako pozorovatel zúčastnil zasedání core týmu Tak jo! Kromě členů samotného core týmu (Peter Bouška, Jarek Jesenský, Lukáš Potužák...) byl přítomen jako pozorovatel Zelených Petr Kutílek. Diskutovalo se o způsobech, jak by Tak jo! mohlo podpořit kampaň Pirátů, Zelených resp. STANu. Hlavními variantami byla logistická podpora pomocí software na koordinaci dobrovolníků používaného En Marche! a organizace předvolebních debat pro členy ostatních stran. K možnosti sdílení osobních/pracovních kampaňových dat jsem se stavěl odmítavě, účast v případných panelových debatách vidím jako možnou a potenciálně přínosnou.
