# Podpořili jsme navýšení rozpočtu pro program Erasmus+

Podpořili jsme více peněz pro program Erasmus+! Máme radost, že se i díky naší podpoře povedlo v Evropském parlamentu dvojnásobně navýšit rozpočet pro program Erasmus+. Rozpočet na roky 2021-2027 tak bude činit 26,2 miliardy eur, což zajistí další rozvoj celého projektu. Jenom v roce 2019 program v Evropě zafinancoval více než 940 000 vzdělávacích zkušeností v zahraničí a přibližně 25 500 projektů.
